Lingose IPSM Notation — Privacy Policy

Last updated: 2026-10-06. Applies to extension version 0.1.0.

Lingose IPSM Notation processes English page text locally in your browser. It does not upload page text, browsing history, typed input or personal information to the developer or third parties. It contains no analytics, advertising trackers or remote executable code.

Page access and processing

Opening the popup reads saved settings, identifies the current tab and performs a read-only check of the current document's support and annotation status. It does not start scanning or converting page text.

The current tab URL is used locally to check page support and target the document. It is not uploaded or saved. The popup explains this check and local text processing before the Apply button.

When you click Apply to current page, a local content script reads eligible text in the top-level HTML document. Text batches are sent through Chrome's internal extension messaging to this extension's background worker, converted using bundled algorithms and dictionary data, and returned to the page. These messages stay inside the browser; they are not network uploads. Page text may itself contain personal information, which follows the same local processing path.

The annotation traversal excludes input controls, editable regions, hidden text, code, scripts, styles, iframes and Shadow DOM. It does not convert form values or HTML attributes. While the document is activated, a local observer handles added or changed text. Browser mutation records may briefly include changes in excluded regions before filtering; those records are not uploaded or persisted by the extension.

Original text, annotation results and restoration records are held in running memory, not saved in extension storage. Restore current page stops processing that document and releases its restoration records as restoration finishes. Website changes are preserved where the extension no longer owns the text. Disabling the feature stops activated sessions and attempts restoration; suspended pages respond when they resume. Refreshing or closing a page ends that document's session.

Saved settings

The extension saves only these fields in chrome.storage.local:

SettingPurpose
enabledWhether IPS notation is enabled.
skipTopYour saved frequency threshold (skip_top).
schemaVersionThe settings format version.
disableRevisionA counter that prevents an older page session from resuming after disable.

Settings persist across browser restarts. The extension does not use Chrome sync or session storage to save product data. It does not persist page text, annotation results, restoration records, page URLs, browsing history or form input. Removing the extension removes its local settings, as described in Chrome's storage documentation.

Network and external links

Conversion works offline using resources installed with the extension. Dictionary files are loaded from the extension package. No external server, Python service or cloud API is used for annotation, and page content is not sold or shared.

The popup offers links to Lingose and GitHub. They open in a new tab only when you click them. Visiting these sites makes ordinary website requests and is governed by those sites' privacy policies. They are learning resources, not annotation services.

This policy describes the extension's behavior. Chrome and websites you visit may perform their own storage and network activity independently.

Permissions

PermissionUse
activeTabTemporary access to the current tab after you invoke the extension.

The production extension requests no all-sites host access, browsing-history permission or automatic scripts on every page. Opening a website alone does not activate annotation.

Limited use

Lingose IPSM Notation's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only for local IPS annotation, page support checks and restoration. The extension does not sell or transfer user data, use it for advertising or creditworthiness decisions, or provide the developer or other people with access to it.

Contact and changes

For project information or privacy questions, use Lingose or the project's GitHub organization. Future changes to processing or storage will be reflected in this policy and the extension's disclosures before release.
